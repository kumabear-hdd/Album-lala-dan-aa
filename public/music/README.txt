Folder ini disiapkan khusus untuk file audio/lagu kenangan Aa & Lalaa:

1. 1000x - Ghea Indrawari (simpan sebagai: 1000x-ghea-indrawari.mp3)
2. Jadian Yuk - Chloe Pawapuwa (simpan sebagai: jadian-yuk-chloe-pawapuwa.mp3)
3. Kita Usahakan Rumah Itu - Sal Priadi (simpan sebagai: kita-usahakan-rumah-itu-sal-priadi.mp3)
4. Night Changes - One Direction (simpan sebagai: night-changes-one-direction.mp3)

Jika file MP3 sudah diletakkan di folder ini, pemutar musik akan otomatis memutar rekaman asli lagu tersebut!
Jika file belum diletakkan, sistem akan memainkan alunan akustik piano/music box bernada lembut yang diselaraskan dengan harmoni lagu tersebut.
